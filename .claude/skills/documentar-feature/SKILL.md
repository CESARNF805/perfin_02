# Processo: documentar feature

Crie ou atualize `Documentacao/<area>/<nome-da-feature>.md`, em que `<area>` é `aplicativo` ou `website`.

Use este template:

```markdown
# <Nome da feature>

## Objetivo
O problema que a feature resolve e para quem.

## Como funciona
Visão técnica: componentes, fluxos e arquivos principais.

## Como usar
Passo a passo para o usuário ou para o desenvolvedor.

## Observações
Limitações, riscos conhecidos e próximos passos.

_Última atualização: AAAA-MM-DD_
```

Regras:
- Escreva em PT-BR, de forma objetiva.
- Não inclua segredos nem dados reais de clientes.
