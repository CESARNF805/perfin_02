# Regras gerais do Perfin_02

- Responder e escrever documentação em português (PT-BR).
- Fazer mudanças pequenas e focadas no que foi pedido.
- Seguir os padrões que já existem no projeto antes de criar novos.
- Não misturar código de `Aplicativo/` e `Website/`.
- Toda funcionalidade nova ou alterada deve ser documentada em `Documentacao/` (skill `documentar-feature`).
- Mudanças relevantes passam pelo fluxo: `architect` → implementação → `tester` → `reviewer` (skill `nova-feature`).
