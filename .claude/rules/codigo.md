# Regras de código do Perfin_02

- Não deixar código morto, imports sem uso nem código comentado.
- Não duplicar lógica; reutilizar o que já existe.
- Preferir a solução mais simples que resolva o problema.
- Toda correção de bug deve vir acompanhada de um teste que reproduza o bug.
- Não remover nem desativar testes para fazer a suíte passar.
- Não alterar backend ou banco de dados sem necessidade explícita.
